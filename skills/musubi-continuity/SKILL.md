# Musubi continuity

Call `musubi_status` for provider health. A failed status call is not an empty
memory search. For one `musubi_remember` result, inspect its returned state and
object ID. `queued` is local; `verified` is remote readback. Never expose a
credential or captured conversation text while reporting health.
